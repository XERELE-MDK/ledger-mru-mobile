# Icon — code walkthrough

[← All features](../README.md) · [How it works](FUNCTIONALITY.md)

Generated, never edited by hand:

```bash
python3 app/branding/make_icons.py --android android/app/src/main/res
```

- 108 grid, drawing inside the central 66 circle.
- A single foreground colour, for the `monochrome` layer.
- The `mipmap-*` PNGs are for Android 7.
