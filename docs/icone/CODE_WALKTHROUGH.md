# Icône — parcours du code

[← Toutes les fonctionnalités](../README.md) · [Fonctionnement](FUNCTIONALITY.md)

Générée, jamais retouchée à la main :

```bash
python3 app/branding/make_icons.py --android android/app/src/main/res
```

- Grille de 108, dessin dans le cercle central de 66.
- Une seule couleur au premier plan, pour le calque `monochrome`.
- Les PNG `mipmap-*` servent à Android 7.
